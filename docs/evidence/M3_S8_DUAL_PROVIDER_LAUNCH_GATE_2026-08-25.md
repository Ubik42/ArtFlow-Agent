# M3-S8 operator-ready dual-provider launch gate

Date: 2026-08-25  
Evidence level: A2 — typed control-plane contracts and recorded provider transports  
Real host, credential inspection, GPU generation, paid call or Unreal write used: no

## Result

ArtFlow can now compile one immutable Scene Package and art-intent hash into two child executions:
one reviewed local Comfy route and one fixed-snapshot OpenAI Images route. Each child owns a
different run ID, execution ID, idempotency key, route fingerprint, capability attestation and
authority kind. Pydantic validation rejects any accidental sharing of those identities.

The operator preview records the exact beauty-only uploads, OpenAI endpoint/model, one-output
contract, output size, estimated and maximum hosted cost, provider-retention assumption, lack of a
provider-enforced cost cap and every unresolved real-host fact. It is data for a human approval
surface, not an authorization generated by the Agent.

## Launch and recovery behavior

Before either child can start, `ProviderComparisonLauncher` verifies:

- an external human-owner authorization bound to the dossier hash and complete plan hash;
- exactly the local-generation and hosted-edit action IDs, never the Unreal return action;
- both durable child states, selected routes and supported attestations;
- both compiled request identities;
- the signed, unconsumed local GPU grant and hosted privacy/cost packet.

The local `ComfyProviderAdapter` now implements the same reconciliable provider port as the hosted
adapter. Both children therefore pass through `ProviderExecutionCoordinator` and the append-only
execution ledger. A completed comparison manifest contains both normalized receipts but deliberately
has no selected candidate. A hosted timeout produces `needs_human_recovery`; restart reuses the local
terminal receipt, preserves hosted unknown completion, and performs no second submission.

Three generated JSON Schemas expose the plan, authorization decision and manifest outside Python.

## Evidence ceiling

This is operator-ready orchestration evidence, not a real two-provider run. The dossier still uses
fixture scene evidence, no secret was inspected, and no request reached ComfyUI or OpenAI. Live API
compatibility, GPU output, provider billing/provenance, real Unreal capture and review-asset return
remain unproven and require separate explicit authorization.
