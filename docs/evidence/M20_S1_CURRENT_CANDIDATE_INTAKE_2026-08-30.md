# M20-S1 — 当前候选评价入口

## 结果

M19 的真实 UE 5.8.1 候选工作没有被转交给历史展示数据。评价器从当前工作定义中的 `plan_id` 定位
项目注册回执，核对回执文件哈希等于工作结果哈希，再读取同目录候选回渲。调用方不能传入文件路径、
评价 JSON 或任意候选身份。

## 技术审查

当前运行 `unreal-artflow-ue-89ac07a74988b8dd2fca9295e141a6fd-ca79f77b487e` 通过 6/6 项：

- 工作结果、Unreal 回执、Stage Request 与 Candidate Plan 身份一致；
- 源关卡执行前后哈希一致；
- 候选关卡严格位于当前 Scene Session 命名空间；
- PCG 生成 12 个实例，未越过当前计划预算；
- 候选回渲尺寸与 Scene Package 相机一致；
- 候选回渲文件哈希与 Unreal 回执一致。

评价以第 9 个 append-only 事件写入；重复调用不增加事件，重启 Reducer 恢复相同记录。独立负例把
实例数提高到 999，PCG 域在视觉评分前被拒绝，证明后续 Visual Critic 没有覆盖硬失败的空间。
