# M20-S3 — 当前候选灯光域定向纠正

## 结果

当前 Scene Session 的视觉裁决只将 `lighting` 标为失败。Correction Planner 由持久裁决、精确候选身份与
父工作回执编译一个内容寻址工作项，同时封存已经通过的 image 与 PCG 证据哈希。调用方不能提交候选路径、
Unreal 属性名或任意补丁结构。

UE 5.8.1 编辑器领取工作后，只允许修改注册灯光组件的强度与色温。最终宿主回执记录：

- 主光强度：`5.5 → 3.2`；
- 主光色温：`4200K → 7200K`；
- PCG 实例：`12 → 12`；
- 保护结构语义指纹：前后一致；
- 源关卡文件哈希：前后一致；
- 新同机位回渲：`9babc128…e2b13e`。

## 恢复与策略纠偏

首次真实执行因纠正合同没有携带源关卡内容哈希而在写入前安全拒绝。合同随后补入技术审查已经封存的
源哈希，失败工作可沿同一内容身份重新排队。恢复后的第一份计划仍与父候选使用相同参数，因此 UE 正确
返回幂等对账、没有伪造视觉变化。策略修正为冷色雨后方向后生成新的内容身份，第二次执行才产生实际灯光
变更。两次无效尝试都保留在 append-only 事件链中，最终状态由第 24 个事件重建。

最终成功工作随后由另一个 UE 5.8.1 进程重新打开。宿主核对同一工作、源关卡、候选语义状态、灯光参数、
PCG 数量、保护结构、回执与回渲哈希后返回 `reconciled`；候选文件与回执哈希不变，事件数仍为 24，重复
Actor、实例、资产和 Provider 副作用为 0。

## 界面与验证

中文场景导演台现在把当前源场景与纠正回渲并列展示，并明确标注“灯光已纠正待复评”，没有提前宣称采用
或发布。1600×1000 与 720×1200 截图均无破图、控制台错误或横向溢出。定向测试 6 项通过，UE 插件以
Development Editor 配置编译成功。

本切片尚未进行纠正结果的独立视觉复评、候选采用或发布。
