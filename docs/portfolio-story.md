# ArtFlow Agent — portfolio story

## One-line pitch

ArtFlow Agent turns a game-art brief into controlled, reviewable ComfyUI iterations while keeping
workflow topology, GPU cost, user constraints, and asset adoption behind explicit engineering
boundaries.

## Problem

ComfyUI can produce strong images, but an unrestricted graph or prompt loop is difficult to review,
repeat, and trust in a production art workflow. A useful agent must do more than call a model: it
must inspect the actual machine, choose only compatible reviewed workflows, preserve art-direction
constraints, stop before costly execution, recover from partial failure, and produce evidence a
human can audit.

## Product decision

ArtFlow deliberately supports two narrow stories:

1. composition-preserving lighting and atmosphere directions for a game-environment graybox;
2. mask-bounded refinement of a selected candidate.

The agent can plan and judge, but it cannot invent a graph. Recipes own topology and allowlisted
slots. Deterministic code owns environment validation, approval, queueing, receipts, technical
checks, packaging, and run-state transitions. A human owns GPU approval and final selection.

## Architecture evidence

```text
brief
  -> typed planner
  -> reviewed plan + human approval
  -> live ComfyUI capability/schema preflight
  -> allowlisted recipe slots
  -> resumable direction runner
  -> workflow hash + receipt + downloaded artifact
  -> technical checks + optional visual rubric
  -> contact sheet + human selection
  -> mask-bounded revision
  -> checksummed delivery package
```

Important tradeoffs:

- The default planner is deterministic. Model-backed planning is opt-in so a demo never silently
  spends API tokens.
- The workflow manifest is the trust boundary. Flexibility is intentionally lower than arbitrary
  graph generation, but compatibility and reviewability are much higher.
- Mock transports cover protocol parsing and safety invariants; real RTX 4080 evidence is the
  milestone gate for visual claims.
- Mutable state lives outside model context in `runs/<run-id>`, so interruptions can resume without
  asking a model to remember prior tool calls.

## Three-minute demo

1. Open the workbench and point out the live ComfyUI/VRAM indicator.
2. Read the brief's preserve and prohibited constraints in the inspector.
3. Show three deterministic directions and the explicit `Approve plan` boundary.
4. Approve and run; direction lanes update independently and completed lanes survive a retry.
5. Compare the generated candidates, open the contact sheet, and make the human selection.
6. Run deterministic asset checks; optionally show the separate multimodal rubric.
7. Apply the arch mask to the selected candidate and run the bounded refinement recipe.
8. Open the delivery ZIP manifest to show recipe versions, workflow hashes, seeds, events, receipts,
   selected result, evaluation output, and file hashes.
