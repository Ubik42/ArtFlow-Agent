# 展示图片说明

本目录保存 README 使用的稳定展示副本，图片均来自 ArtFlow 项目自有演示场景的实际运行：

- `scene-lab-*`：中文 Scene Lab 的四个生产案例；
- `image-to-3d-*`：项目自有概念参考及其 Unreal 候选；
- `pbr-*`：生成并验证的玄武岩材质及 Unreal 回渲；
- `multi-domain-*`：多域场景改造的美术机位与验证机位；
- `correction-*`：灯光失败与定向纠正结果。

这些文件只用于稳定呈现，不是设计稿或后期拼接状态。对应的原始回执、内容哈希和验证记录保存在仓库的 `docs/evidence/` 与运行制品中。
